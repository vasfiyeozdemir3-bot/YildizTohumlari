# Yıldız Tohumları – 3B Açık Dünya Prototipi

**Oyna:** https://vasfiyeozdemir3-bot.github.io/YildizTohumlari/

Unity 6 ile hazırlanmış 3B açık dünya prototipi. Gece çökmeden caddedeki 10 yıldız tohumunu (küre) 60 saniye içinde yoldaki yuvalara it; sağa sola giden kutulara değersen oyun baştan başlar.

**Kontroller:** W/A/S/D veya ok tuşları – hareket • Fare tekerleği – yakınlaştırma • R – yeniden başlat
